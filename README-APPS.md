3つの独立したアプリに分離しました。

```

│   ├── index.html
│   └── app_home_btn.js
│
├── app2-cafeteria/          # ✅ 食堂混雑状況アプリ（独立版）
│   ├── index.html
│   └── app_home_btn.js
│
├── app3-shops/              # ✅ 商店・待ち時間アプリ（独立版）
│   ├── index.html
│   └── app_home_btn.js

├── menu-hub.html             # ✅ 統合メニューハブ（アプリ一覧）
│
└── [その他の既存ファイル]
```

## 🚀 使い方

### 1. アプリメニューから開く
`menu-hub.html` をブラウザで開くと、3つのアプリへのリンクが表示されます。

### 2. 個別アプリを直接開く
- **タイムテーブル**: <http://localhost/app1-timetable/> または `app1-timetable/index.html`
- **食堂混雑状況**: <http://localhost/app2-cafeteria/> または `app2-cafeteria/index.html`
- **商店・待ち時間**: <http://localhost/app3-shops/> または `app3-shops/index.html`

### 3. ホームボタンで戻る
各アプリ左上の「◀ ホーム」ボタンで、メニューハブに戻ります。

## ✨ 各アプリの特徴

### 📅 タイムテーブルアプリ (app1-timetable)
- 新緑祭のイベント時間表示
- 現在のイベント状態をハイライト
- カウントダウン表示機能

### 🍚 食堂混雑状況アプリ (app2-cafeteria)
- 食堂の現在の混雑度を表示
- リアルタイム更新（20秒ごと）
- 混雑度に応じた色分け表示

### 🛍️ 商店・待ち時間アプリ (app3-shops)
- 商店の在庫調査表示
- 販売情報表示
- リアルタイム更新（15秒ごと）

## 🔗 リンク構成

- **メニューハブ** → 各アプリへのリンク
- **各アプリ** → ホームボタン（メニューハブに戻る）

## 📝 注意事項

- 各アプリは完全に独立しています
- スマートフォン対応（レスポンシブデザイン）
- ホームボタンはブラウザ互換性を考慮した実装
- キャッシュ機能で、ネットワーク通信がない場合も一部表示可能
